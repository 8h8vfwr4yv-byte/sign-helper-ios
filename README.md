# IPA 签名助手（SignHelper）

使用 SwiftUI 编写，目标 iOS 27.2 SDK（GitHub Actions `xcode-27` runner + XcodeGen 构建），输出 Xcode 项目并打包为未签名 IPA 供侧载。本项目为**技术学习演示项目**。

## 备注说明（重要）

- **iOS 官方 SDK 没有内置代码签名接口**：任何“在 App 内直接给 IPA 签名”的实现，都依赖苹果未公开的认证流程或外部开源组件，并非系统提供的能力。
- 本项目为**技术学习演示**，用于理解 IPA 结构、签名状态与描述文件（Provisioning Profile）的解析方式。

## 模式区分

| 模式 | 说明 |
| --- | --- |
| **后端签名（可选对接）** | 在 App 内填写你自己签名服务器的接口地址与 Apple ID，App 按约定把 IPA 提交到该接口、接收返回的已签名 IPA 并导出。接口约定：`POST multipart/form-data`。登录校验：字段 `apple_id`、`password`、`action=login`，返回 HTTP 200 视为成功；签名：字段同上并附文件字段 `ipa`，成功时直接返回签名后的 IPA 数据。密码仅在内存中使用、不保存、不写入日志。 |
| **本地签名（实验性）** | 依赖外部开源签名组件（如 ldid / zsign 类工具）在本机重签名，**标记为实验性功能**；本构建未集成此类组件，在高版本原生环境下可能失效——该模式只记录流程日志并导出原始 IPA 副本，不冒充已签名。 |

没有自建后端时，成熟可行的路线仍是 **AltStore（电脑 AltServer 执行签名）** 或 **SideStore（本机签名）**，App 内附路线说明。

## 功能

- **文件选择器加载本地 IPA**：导入 IPA 库（文件保存在 App 沙盒），支持多选
- **解析展示**：应用图标、名称、Bundle ID、版本、最低系统、大小
- **签名状态解析**：是否已签名；解析 `embedded.mobileprovision` 的团队、Team ID、创建/到期时间与剩余天数，按到期临近排序、过期标红
- **Apple ID 登录界面**：位于“签名”页后端模式下（见上方模式说明，密码不落盘、不进日志）
- **签名状态日志**：导入、删除、签名尝试与结果全程记录，可查看/清空（不含密码等敏感信息）
- **导出结果**：详情页导出原始 IPA；签名页导出后端返回的签名结果 IPA

## 免费 Apple ID 的限制

使用个人免费 Apple ID 签名（免费开发证书）有以下硬性限制：

- **7 天过期**：免费证书与描述文件有效期只有 7 天，到期后 App 无法打开；用同一 Apple ID 续签即可恢复，App 数据不丢失
- **App 数量上限**：同一台设备上由免费证书签名的 App 最多同时存在 **3 个**；7 天内可注册的 App ID 数量也有上限（约 10 个）
- **能力受限**：推送通知、App Groups 等部分能力在免费签名下不可用或受限

## 个人使用范围提示

- 本工具仅供**个人学习与自用**：为自己拥有的设备、自己有权使用的 IPA 做签名管理与实验
- 请勿用于分发、代签收费、绕过付费或侵犯他人权益的用途
- 本 App 自身也是未签名 IPA，首次安装同样需要先用 AltStore / SideStore 等工具签一次（所有侧载工具的共同前提）

## 实现要点

- `Sources/ZipReader.swift` — 极简 ZIP 中央目录解析 + deflate 解压（系统 Compression 框架），IPA 与描述文件解析
- `Sources/App.swift` — 四个标签页：IPA 库 / 签名（模式区分 + 登录 + 导出）/ 日志 / 说明
- 最低系统 iOS 17.0；工程由 XcodeGen（`project.yml`）生成
